# Robot Drive Simulator

A small browser-based robotics project that demonstrates **differential drive**, a common way two-wheel robots move.

## What it does

- Lets you control the left motor speed
- Lets you control the right motor speed
- Shows the robot moving on a field
- Displays whether the robot is moving forward, backward, turning, or spinning
- Draws the robot's path as it moves
- Includes start, stop, and reset controls

## Why the robot turns

A two-wheel robot changes direction by changing the speed of each wheel.

Examples:

- Left = 50, Right = 50 → moves straight
- Left = 70, Right = 30 → turns
- Left = 50, Right = -50 → spins in place
- Left = -40, Right = -40 → moves backward

## Run it

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md`.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
